# 风野奇旅 · 守望之境（v4.1 光影与归途）

一款基于森林、高山、草原短片美术制作的原创横版平台小游戏。现在可选择三位旅行者，与白猫穿越六处风景：日光草原、古树秘径、云上山脊、潮汐群岛、落日沙海、萤晶洞窟。

v4 为六张地图增加分层环境装饰、主题光色、柔和投影、近景植物和岩石，以及营地抵达演出。普通关卡约 4 秒；最终关约 7 秒，旅人与白猫抵达旗帜后，六处风景的微光连成旅途路线，再显示原有成绩。按 Enter、空格、Esc 或点击“跳过动画”可立即查看成绩。系统开启“减少动态效果”时采用约 1 秒的短淡入，不移动演出角色。离开窗口会暂停演出，返回后继续；声音沿用原开关。

演出仅改变画面，不移动真实玩家或白猫，不增加金币，也不消耗关卡用时；碰撞、战斗和存档沿用原规则。新增景物是装饰，不是可站立的平台。六处微光代表游戏的六张地图，不表示中途选关时已完成全部关卡。

## 直接试玩

[在线开始游戏](https://zjh-b.github.io/windward-trails/) · [GitHub 源码仓库](https://github.com/zjh-b/windward-trails)

本包为 v4.1；在线版是否已更新，以部署完成后的页面为准。

完整解压文件夹后，双击 **index.html**。不需要安装库，也不需要联网，推荐使用电脑上的 Edge 或 Chrome。

也可双击 `Start Game.cmd`，或运行 `python run_game.py`。启动器会在本机空闲端口启动服务并打开浏览器；关闭服务窗口即可结束。只有这种启动方式需要 Python，游戏本身可直接离线打开。

## 操作和目标

手机竖屏打开时，点击右上角 **横屏玩**，然后横握手机。浏览器允许时进入原生全屏并请求横向；不支持时会切换为页面横屏，触屏按钮随画面一起旋转。点击同一位置的 **退出横屏** 可恢复原布局，也可以直接转动手机继续使用普通响应式画面。

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或 ← / → |
| 跳跃 | 空格 / W / ↑，按住跳得更高 |
| 奔跑 | Shift |
| 射击 | 按住 F / J，朝角色面向的方向发射 |
| 换弹 | E；空弹夹自动换弹，备用弹药无限 |
| 暂停、继续 | Esc / P |
| 重开本关 | R |
| 声音开关 | M 或右上角按钮 |

手机和平板显示左右、跳跃、射击、换弹和快跑开关，可同时按压移动、跳跃与射击。主菜单可选择人物，从任意一关开始；小屏幕菜单可上下滚动。浏览器会记住所选人物、地图、通关记录，并自动保存当前旅程。刷新页面后点击“继续上次”，从最近检查点恢复，保留生命、金币、已击败的守卫、Boss 剩余血量与弹夹状态。重新出发会替换存档；生命耗尽或全程完成后清除待继续的旅程。

## 人物与地图

| 人物 | 特点 | 普通速度 / 奔跑速度 / 起跳速度 |
| --- | --- | --- |
| 阿岚 | 红斗篷、均衡手感，适合初次出发 | 320 / 420 / 680 |
| 森芽 | 绿斗篷、羽毛宽檐帽和背包，跑得更快 | 350 / 455 / 680 |
| 星澜 | 蓝斗篷、尖帽和星徽，跳得更高 | 305 / 400 / 740 |

速度单位为游戏坐标/秒。三位人物均为三颗心、相同碰撞尺寸；所有地图都可用普通移动速度完成。人物能力无需解锁，重试、复活和换关会保留选择。

| 地图 | 场景与路线 |
| --- | --- |
| 日光草原 | 起伏草浪，熟悉跳跃与金币收集 |
| 古树秘径 | 层叠树影、移动平台与树根 |
| 云上山脊 | 雪峰云海、断崖与弹跳垫 |
| 潮汐群岛 | 碧海、棕榈、连续岛屿与移动平台 |
| 落日沙海 | 沙丘石拱、仙人掌与连续弹跳 |
| 萤晶洞窟 | 发光晶石、悬垂岩柱与高低平台 |

收集金币，跨过缺口，击败 Boss 后抵达关尾的大旗营地。从上方落在甲虫身上可以踩掉它，也可远程击败；守卫和 Boss 需要射击。侧面碰撞、敌方弹丸、危险陷阱和坠落会损失一颗心。首次点亮检查点恢复三颗心；受伤后回到最近检查点、补满弹夹，并获得短暂无敌。已击败的守卫和 Boss 的剩余血量保留。三颗心耗尽可重试本关。完成关卡后点击按钮继续下一关。第六关显示本次旅程的总金币和用时；从中途地图开始只累计本次游玩的关卡。白猫跟随，不参与伤害。

### 陷阱、守卫与 Boss

| 地图 | 特色陷阱 | 远程守卫 / Boss |
| --- | --- | --- |
| 日光草原 | 荆棘丛：接触受伤，跳过 | 草籽哨兵 / 荆冠守望者 |
| 古树秘径 | 沼泽：地面移动减速，跳跃脱离 | 苔木守卫 / 苔沼长老 |
| 云上山脊 | 冰刺：黄色预警后周期升起 | 冰晶哨兵 / 霜角巨灵 |
| 潮汐群岛 | 潮汐喷涌：预警后喷发 | 贝壳守卫 / 潮汐巨钳 |
| 落日沙海 | 流沙：减速、逐渐下陷，及时跳跃 | 沙岩哨卫 / 沙丘石像 |
| 萤晶洞窟 | 晶簇脉冲：预警后释放能量 | 晶石守卫 / 萤晶核心 |

每图两名守卫、一位 Boss。发亮的蓄力环表示即将发射；平台能阻挡双方弹丸，Boss 半血后攻击更频繁。击败 Boss 恢复一颗心并解除终点屏障。流沙约 3.8 秒完全下陷后扣血；离开流沙会快速恢复下陷值。沼泽本身不直接扣血。

| 角色武器 | 弹夹 | 换弹时间 | 单发伤害 |
| --- | --- | --- | --- |
| 阿岚 · 风种 | 6 发 | 1.25 秒 | 1 |
| 森芽 · 叶矢 | 8 发 | 1.45 秒 | 1 |
| 星澜 · 星火 | 4 发 | 1.6 秒 | 2 |

左上角显示弹量、换弹进度和剩余时间。换弹期间不能射击，但仍可移动跳跃；暂停会冻结换弹与所有战斗计时。

## 内容

- 六个不同背景与平台布局的完整关卡；金币、原创甲虫敌人、检查点、移动平台、弹跳垫和终点。
- Blender 烘焙的三位旅行者与白猫 12 帧透明动画，六张场景背景；新增人物具有独立建模的帽子与配饰。
- 固定 120 Hz 物理、短跳/长跳、离地宽容与跳跃缓存。
- 原三种氛围音轨按场景复用，轻量合成音效、暂停、选关选人、全屏和触屏操作。
- 单机离线游戏；游玩不调用远程接口、不收集个人信息。本机存储保存偏好、通关记录和最近旅程；不同设备、不同浏览器或在线/离线入口之间不会自动同步。清除浏览器存储会清除这些记录。

这是 2.5D 游戏：画面使用真实 3D 场景及角色的烘焙素材，碰撞和操作在二维平面进行。平台闯关机制借鉴这一类型的常见玩法，没有使用任天堂角色、关卡或音效。

## 源码

- `core.js`：关卡数据、物理、碰撞、金币、敌人和状态。
- `combat.js`：地图陷阱、守卫与 Boss、双方弹丸、弹夹和换弹。
- `game.js`：Canvas 渲染、输入、音效、菜单和状态反馈。
- `scenery.js`：六种主题的远近景、缓存光束、局部光池和角色/平台投影。
- `finale.js`：独立通关画面时间轴，不改动物理或成绩状态。
- `index.html`、`style.css`：游戏界面与响应式布局。
- `assets/`：已烘焙的背景、角色图集和声音，独立试玩所需素材均在这里。
- `export_assets.py`、`pack_assets.py`：素材再生成脚本。
- `export_expansion.py`、`pack_expansion.py`：新增三张地图与两位人物的 Blender 建模、渲染和图集打包。
- `package_game.py`：验证并生成独立游戏 ZIP，排除原始渲染中间文件。
- `tests/`：机制测试与真实浏览器操作测试；`qa/`：截图和验证记录。
- `DESIGN.md`、`PLAN.md`、`EXPANSION.md`：设计与实现记录。

开发验证：`node --test tests/core.test.cjs tests/combat.test.cjs tests/presentation.test.cjs`。浏览器验证需要 Python Playwright 与已安装的 Chromium，运行 `python tests/browser_qa.py` 和 `python tests/browser_traps.py`，会自动启动并清理临时本地服务。测试包含六关真实键盘战斗通关、换弹与存档恢复、选择记忆、离线素材加载，以及手机竖屏和横屏多指操作；陷阱测试通过真实按键走入沼泽和流沙，再跳跃脱离。纯机制测试覆盖全部 18 种人物与地图组合。

浏览器测试通过后运行 `python package_game.py`，会检查 JavaScript、机制测试、启动器和资源，生成上级目录中的 `windward_trails_game_v4_1.zip`。验证记录及文件校验值保存在 `qa/verification.json`。旧版 ZIP 保留。

v4.1 打包前还需运行 `python tests/browser_presentation.py`：覆盖键盘焦点与跳过按钮位置、自然结束、演出期间物理/成绩冻结、帮助与失焦中断、手机触屏跳过、减少动态和离线加载。演出专项测试会准备终点附近状态后触发真实通关判定，完整六关仍由上面的真实键盘流程验收，两者各自记录结果。

`python tests/performance_presentation.py` 可在没有其他浏览器测试同时运行时，对比本机 HEAD 旧版与当前版本的绘制频率。`python tests/capture_finale.py` 可录制实际浏览器演出，输出上级 `output_game_v4/finale-preview.mp4`；这是演出预览，不是六关过程录像。

## 重新制作素材

试玩和改关卡无需 Blender。需要重新烘焙 3D 角色或场景时，把本文件夹放回原 `forest_mv` 工程内，再运行：

```powershell
& '..\tools\blender-4.5.15-windows-x64\blender.exe' -b --python-exit-code 1 --python '.\export_assets.py'
python .\pack_assets.py
& '..\tools\blender-4.5.15-windows-x64\blender.exe' -b --python-exit-code 1 --python '.\export_expansion.py'
python .\pack_expansion.py
```

再生成需要原工程的 `forest_stroll_v2.blend`、`grassland_stroll.blend`、`alpine_stroll.blend` 及三条 WAV 音轨；存在 `forest_stroll_v3.blend` 时会优先使用其中的角色。Python 打包脚本需要 Pillow 和 FFmpeg。游戏 ZIP 已含烘焙结果，不重复放入体积较大的原始 Blender 工程。
